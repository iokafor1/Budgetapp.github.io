DAYMARK — PERSONAL FINANCE TRACKER

INSTALL ON IPHONE
1. Publish the contents of this folder to a static website with HTTPS.
2. Open the HTTPS address in Safari on your iPhone.
3. Tap Share, choose “Add to Home Screen”, then tap Add.
4. Launch Daymark from its home-screen icon. The app shell is cached for offline use after its first load.

UPDATE AN EARLIER COPY
This updated download does not automatically replace files already hosted on a website or an app icon already on your Home Screen. Replace the old website files with all the files from this package, reload the website in Safari, and if the old appearance persists, remove the old Home Screen icon and add the updated site again.

SCREENSHOT SCANNING
Tap “Scan screenshot” and choose an image from Photos. OCR runs in the browser. The screenshot is not uploaded. The first scan downloads the OCR JavaScript and English recognition model from jsDelivr, so internet is needed to scan. Recognition can misread amounts, dates or merchants; review every suggested transaction before saving. A category you select is remembered for the same merchant on this device.

DATA AND PRIVACY
Transactions, your chosen name, category suggestions, budgets and net-worth items are stored locally in this browser. They are not synced or backed up. Avoid entering private financial details on shared devices. Screenshots are processed in memory and are not saved by Daymark.

The default currency is USD. Edit the suggested monthly budgets and enter your preferred name in the app.
